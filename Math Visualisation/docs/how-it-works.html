The lifecycle: who calls what, and when

Every project has the same eight parts. Only main.js and input.js call them, always at the same moments:

Page loads

called by main.js
setup()
every project, once: connect its buttons

Menu choice

called by main.js
leave() enter()
the old project pauses, the new one starts; panel says which controls to show

Every frame

called by main.js
update(dt) draw()
about 60 times a second: first change the state, then show it

Mouse

called by input.js
grab(world) drag(world)
take the drag, or return false and the view pans

One frame in detail

update(dt)
change the state
e.g. Run takes the steps that are due
clearCanvas()
empty canvas
view.js
drawGrid()
grid and axes
grid.js
draw()
the project
projects/
drawGridLabels()
numbers on top
grid.js

A project never calls its own parts, never redraws, and never starts a timer. Movement over time belongs in update(dt).

6

Adding a new project

1Copy the template

Copy project-template.js to js/projects/name.js, then fill in its eight parts. Add name-math.js if it has a rule to compute.

2Give it controls

In index.html: an <option value="name"> in the menu and a <div> whose id matches panel.

3Register it

In main.js: import it and add one line to the projects list.

If a part is missing, the page stops with a message naming it, for example: Project "name" is missing: leave.

Conclusion
The math never sees a pixel, and the coordinate system never sees the math.
