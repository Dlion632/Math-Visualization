The eight parts every project has, and the moment each one is called.

1 — COPY

In js/projects/, copy project-template.js to name.js. Keep its three sections: State, Helpers, Lifecycle.

2 — FILL

Fill in the eight parts. Empty is allowed, missing is not: when the page loads, main.js names any missing part.

3 — REGISTER

In index.html add an <option value="name"> and a controls <div>. In main.js import it and add it to projects.

RULES

  • Keep all eight parts, even when empty.
  • A project never calls its own parts, never redraws, never starts a timer.
  • Math goes in name-math.js: numbers only.

STATE + HELPERS

  • State: one object holding everything the project remembers, e.g. step, point, running.
  • Helpers: small functions such as reset() and takeStep().
  • Nothing outside the file uses either.

PANEL + SETUP()

  • panel: the id of the project's controls <div> in index.html.
  • setup(): once, when the page loads. Connects buttons with addEventListener.
  • A button only changes the state. The next frame shows it.

LEAVE() + ENTER()

  • The menu changes project: leave() on the old one, then enter() on the new one.
  • leave() pauses. Tiny Steps sets running = false.
  • enter() is often empty: the state is kept between visits.

UPDATE(dt)

  • Every frame, before draw(). The only place where things move over time.
  • dt = seconds since the last frame: about 1 ÷ 60 ≈ 0.017.
  • Collect dt and act when enough has built up: 0.15 s collected → one tiny step.

DRAW()

  • Every frame, after update(dt). Shows the state and never changes it.
  • Uses the pens with world coordinates: drawPoint, drawVector, drawPath.
  • The grid comes before it and the numbers after: not the project's job.

GRAB(world) + DRAG(world)

  • grab: the mouse was pressed here. Return true to take the drag, false to let the view pan.
  • drag: called on every mouse move while the project holds the drag.
